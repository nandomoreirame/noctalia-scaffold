## Install

Symlink this repo into `~/.local/share/noctalia/plugins/<dir>`, add `nandomoreirame/scaffold` to `[plugins] enabled` in `plugins.toml`, and add `[widget.<name>] type = "nandomoreirame/scaffold:bar"` to the bar.
